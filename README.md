## Monitoramento de API

O arquivo `desafio_api.py` simula a análise de respostas de diferentes endpoints através de códigos HTTP.

O exercício trabalha conceitos como:

- Funções
- Listas
- Laços de repetição
- Estruturas condicionais
- Análise de códigos HTTP
- Cálculo de percentual de sucesso
- Identificação de erros consecutivos
- Classificação de endpoints

Exemplo de endpoints utilizados:

```text
/login
/produtos
/pedidos
```

## Mini CRM

O diretório `mini_crm/` contém um pequeno sistema para gerenciamento de leads executado pelo terminal.

Estrutura:

```text
mini_crm/
│
├── app.py
├── control.py
├── model.py
│
└── data/
    ├── leads.json
    └── lead.csv
```

Entre as funcionalidades desenvolvidas estão:

- Cadastro de leads
- Listagem de leads
- Busca de leads
- Armazenamento de dados utilizando JSON
- Exportação de dados para CSV

O projeto também introduz a separação de responsabilidades entre diferentes arquivos, aproximando a estrutura de conceitos utilizados em arquiteturas como MVC.

## Jogo de Adivinhação

O diretório `Semestre_02/desafio_extra/` contém um jogo de adivinhação de palavras inspirado no Jogo da Forca.

O programa utiliza:

- Dicionários
- Listas
- Loops
- Estruturas condicionais
- Validação de entradas
- Controle de tentativas
- Manipulação de strings

O usuário escolhe uma categoria e uma posição de palavra e possui até seis tentativas incorretas para descobrir a palavra através das letras.
